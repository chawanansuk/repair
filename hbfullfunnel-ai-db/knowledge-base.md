1. **ไม่ได้เปิดหน้าเพจจริง** — environment นี้ถูกตั้ง network policy บล็อกเว็บภายนอกทั้งหมด (facebook.com, เว็บ archive, Google cache ฯลฯ) เหลือเพียง WebSearch จึงได้เฉพาะสิ่งที่ search engine เคย index
2. **ข้อความโพสต์เป็น "ท่อนเปิด" ที่ถูกตัด** ไม่ใช่โพสต์เต็ม (ยกเว้นชื่อโพสต์ Lemon8/TikTok ที่มักเป็นชื่อเต็ม)

4. **ไม่มีคอมเมนต์ ไม่มียอด engagement รายโพสต์**
5. ทุก record มี source URL ตรวจย้อนได้ | สิ่งที่ไม่แน่ใจถูกติดป้าย confidence ต่ำแยกไว้ — **ไม่มีการแต่งเติมเนื้อหา**
