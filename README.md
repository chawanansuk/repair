# ระบบรายงานงานซ่อมบำรุงรายเดือน (Google Sheet + Apps Script)

ดึงข้อมูลจากชีตหอพัก (แท็บ "งาน") แบบ **อ่านอย่างเดียว** มาสร้างรายงานใน
Google Sheet **ไฟล์ใหม่แยกต่างหาก** — ไม่แตะข้อมูลหรือสคริปต์ของชีตต้นทางเลย

- แผนงาน/สถาปัตยกรรม: [PLAN.md](PLAN.md)
  (ทางเลือกแบบสูตรล้วนไม่ใช้สคริปต์: [PLAN-SIMPLE.md](PLAN-SIMPLE.md))
- โค้ด: [`src/Code.gs`](src/Code.gs) และ [`src/appsscript.json`](src/appsscript.json)
- ฟอร์มแจ้งงานสำหรับลูกน้อง (ต่อท้ายแท็บ "งาน" อัตโนมัติ): [FORM-SETUP.md](FORM-SETUP.md)
  + [`src/form-bridge/`](src/form-bridge/)

## สิ่งที่ได้

| แท็บ | เนื้อหา |
|---|---|
| **รายงานรายเดือน** | dropdown เลือกเดือน/ปี → ส่วน A สรุปตามประเภท + ค่าใช้จ่ายรวม, ส่วน B รายห้อง (เรียง ตึก → ห้อง), ส่วน C พื้นที่ส่วนกลาง — จัดรูปแบบพร้อมพิมพ์ A4 |
| **สรุปทั้งปี** | ตาราง 12 เดือน × ประเภทงาน (จำนวนงานเสร็จ + ค่าใช้จ่ายรวมต่อเดือน) |
| **_data** (ซ่อน) | แคชงานสถานะ "เสร็จ" ที่ normalize แล้ว — ทำให้สลับเดือนได้ทันทีโดยไม่ต้องอ่านชีตต้นทางซ้ำ |

อัปเดตข้อมูลได้ 2 ทาง: เมนู **รายงานซ่อมบำรุง → 🔄 รีเฟรชรายงาน**
และ trigger อัตโนมัติวันละครั้ง ตี 5 เวลาไทย พร้อมประทับเวลารีเฟรชล่าสุดมุมรายงาน

## วิธีติดตั้ง (ครั้งเดียว ~5 นาที)

1. **สร้าง Google Sheet ไฟล์ใหม่** (ตั้งชื่อเช่น "รายงานงานซ่อมบำรุง")
   — อย่าสร้างในไฟล์ชีตหอพักเดิมเด็ดขาด
2. ในไฟล์ใหม่: เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ในตัวแก้ไข Apps Script:
   - วางเนื้อหา [`src/Code.gs`](src/Code.gs) ทับไฟล์ `Code.gs` เดิม
   - เปิด ⚙️ Project Settings → ติ๊ก *Show "appsscript.json" manifest file*
     แล้ววางเนื้อหา [`src/appsscript.json`](src/appsscript.json) ทับ
     (สำคัญ: `timeZone: Asia/Bangkok` ทำให้ trigger ตี 5 เป็นเวลาไทยจริง)
4. แก้บรรทัดบนสุดของ `Code.gs`:
   ```js
   SOURCE_SPREADSHEET_ID: 'ใส่_ID_ชีตหอพักตรงนี้',
   ```
   ใส่ ID จาก URL ชีตหอพัก (ข้อความระหว่าง `/d/` กับ `/edit`)
5. กด **บันทึก** แล้วเลือกฟังก์ชัน **`setup`** → กด **Run** → อนุญาตสิทธิ์ตามที่ถาม
   (สิทธิ์ที่ขอ: อ่าน/เขียนสเปรดชีต + สร้าง trigger — ใช้กับบัญชีคุณเองเท่านั้น)
6. เสร็จแล้ว — `setup` จะสร้างแท็บทั้งหมด, dropdown, trigger รายวัน
   และดึงข้อมูลรอบแรกให้อัตโนมัติ (ลบแท็บ `Sheet1` เปล่าๆ ทิ้งได้)

## เกณฑ์ตรวจรับ (ทดสอบตามนี้)

1. **สลับ dropdown เดือน** ที่ B2 → รายงานต้องเปลี่ยนตามภายในไม่กี่วินาที
2. **วันที่สองรูปแบบ** — หาแถวในชีตต้นทางที่วันที่เป็นเซลล์ Date จริง 1 แถว
   และเป็นข้อความ `dd/MM/yyyy` 1 แถว (เดือนเดียวกัน สถานะเสร็จ) → ต้องขึ้นครบทั้งคู่
   (แถวปี พ.ศ. เช่น 2569 จะถูกแปลงเป็น ค.ศ. ให้เอง)
3. **งานส่วนกลาง** (ห้อง = "ส่วนกลาง") ต้องอยู่เฉพาะส่วน C ไม่โผล่ในส่วน B
4. **ยอดรวมค่าใช้จ่าย** แถว "รวมทั้งเดือน" ในส่วน A ต้องเท่ากับบวกมือ
   (ช่องค่าใช้จ่ายว่างนับเป็น 0) และเท่ากับผลรวมส่วน B + ส่วน C
5. **ชีตต้นทางไม่ถูกแตะ** — เปิดชีตหอพัก ดู File → Version history
   ต้องไม่มี revision ใหม่จากการรีเฟรชรายงาน

## หมายเหตุความปลอดภัย

- โค้ดเรียกชีตต้นทางที่จุดเดียว (`readSourceRows_`) ด้วย `getValues()` อ่านอย่างเดียว
  ไม่มีคำสั่งเขียนใดๆ ต่อไฟล์ต้นทาง
- สคริปต์และ trigger ทั้งหมดอยู่ในโปรเจกต์ของไฟล์รายงานใหม่
  ไม่เกี่ยวกับ Apps Script เดิมของชีตหอพักที่ dashboard ใช้งานอยู่
